O que é vazamento de dados?

Vazamento acontece quando informação do conjunto de teste influencia o treino do modelo. A prova deixa de ser uma prova, e a nota fica inflada.

Aqui, os dados são puro ruído: não existe padrão nenhum para aprender. Um modelo honesto deveria ficar perto de 50% de acerto.

Como funciona

  1. Um script em Python sorteia dados sem padrão e treina o modelo.
  2. O experimento roda duas vezes: do jeito errado e do jeito certo.
  3. Os resultados vão para um arquivo JSON que esta página lê e desenha.
